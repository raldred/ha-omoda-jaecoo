First release of my Unofficial Omoda/Jaecoo integration for Home Assistant. It connects to the API used by the European Omoda/Jaecoo app.

- Battery, range, charging status and remaining charge time.
- Door/window states, cabin temperature and other vehicle readings.
- Optional location tracking and lock/climate controls.
- Email or phone sign-in, using a password or one-time code.
- `omoda_jaecoo.refresh_status` to refresh cloud data without waking the car.

Tested in the UK. Controls are off by default, and readings can be stale when the car's asleep.

Requires Home Assistant **2026.7.1 or newer**. You can install it as a HACS custom repository or use the ZIP below. [Setup instructions and current limitations](https://github.com/raldred/ha-omoda-jaecoo#installation).
