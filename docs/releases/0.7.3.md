The estimated battery energy sensor now uses the last-known battery percentage, even when the car is asleep and its report is stale. It no longer needs a recent report to calculate the estimate.

The source report time and freshness are still shown in the entity attributes. Missing or unreliable battery data stays unknown, and a failed cloud connection makes the entity unavailable.

Your configured capacity is kept. Update through HACS and restart HA; no extra setup is needed. No vehicle wake commands or additional API requests are added.
